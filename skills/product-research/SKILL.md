# 产品调研

## 使用时机

当任务需要外部证据支持产品判断时，使用本 skill：

- 进入新产品或新方向前了解行业。
- 分析直接竞品和间接竞品。
- 汇总行业报告、技术文档或产品资料。
- 为产品方案提供趋势、机会或差异化依据。

开始时写明：`正在使用 product-research 执行调研。`

## 执行流程

### 1. 写调研计划

在搜索前完成以下内容：

```text
【调研计划】
主题：
决策问题：本调研必须回答什么问题？
范围：包含什么；不包含什么
时间范围：
直接竞品候选：
间接竞品候选：
负责人：
截止时间：
交付物：总结报告
```

决策问题必须能由证据回答。问题过宽时，缩小范围并记录缩小理由。

### 2. 收集并检查来源

按以下优先级搜索：

1. 官方产品 blog、changelog、文档和试用流程。
2. 第三方研究机构、行业组织和公开数据。
3. 官方定价页、案例和招聘信息。
4. 有出处的访谈、评测或用户反馈。

每条来源记录：

```text
标题：
机构或作者：
日期：
URL：
类型：报告 / 技术文档 / blog / changelog / 试用 / 评测
来源角色：第三方 / 一级相关方 / 用户
可信度：高 / 中 / 低
支持的主张：
限制：
```

质量规则：

- 关键主张必须有原文链接或出处。
- 过期材料标出日期，并降低其权重。
- 厂商材料可以说明产品能力，不能单独证明市场规模或用户效果。
- 匿名转述、无出处截图和无法复核的说法不能支撑关键结论。
- 事实、推断和假设分开写。

### 3. 建立竞品集合

按主问题和用户重叠程度分类：

- 直接竞品：解决相同主问题，服务相近用户。
- 间接竞品：解决相邻问题，或提供可替代路径。

直接竞品至少收集 2 个，间接竞品至少收集 1 个。市场材料不足时，列出已找到的全部对象，并说明数据缺口。

### 4. 填写竞品记录

每个竞品使用相同字段：

```text
【竞品】
产品名称：
类型：直接 / 间接
目标用户与场景：
用户规模：数值或未知
产品定位：一句话
相关功能：
功能组织方式：
核心对象与关系：公开可知内容
主路径：
明显摩擦：
商业模式：
证据链接：
未验证内容：
```

每个字段都写事实或“未知”。不要用推测填充未知内容。

### 5. 写总结报告

使用以下结构：

```markdown
# 调研总结：<主题>

## 决策问题

## 1. 行业趋势
- 趋势：证据链接；事实与推断分开。

## 2. 机会点
- 机会：依据、受益用户、主要风险、证据链接。

## 3. 差异化方向
- 方向：服务对象、解决的问题、放弃该方向的代价、证据链接。

## 4. 未验证假设
- 假设：验证动作、负责人、截止时间。

## 附录
- 来源记录
- 竞品记录
```

每个趋势、机会和差异化方向都必须回链到来源记录或竞品记录。

## 完成闸门

只有全部条件满足时，才写“调研完成”：

- 调研计划已写，决策问题清晰。
- 关键来源通过质量检查，或已标出限制并降低权重。
- 直接竞品和间接竞品已分开。
- 每个竞品使用相同字段，未知内容明确标记。
- 主来源至少包含 blog、changelog 或实际试用中的一类材料。
- 报告包含行业趋势、机会点和差异化方向。
- 未验证假设单独列出，并有验证动作。

条件未满足时，报告当前完成度和缺口，不能写“调研完成”。

## 停止条件

无法取得任何可信来源时，输出阻塞清单并停止下结论。用户只需要快速印象时，可以输出简报，并标记“非正式调研，未通过完成闸门”。
